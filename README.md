# Sistema BIM de Quantificação e Orçamentação

## Descrição do projeto

O Sistema BIM de Quantificação e Orçamentação é uma aplicação web desenvolvida para apoiar estudos preliminares de obras, permitindo estimar automaticamente quantitativos de materiais e custo total da construção a partir de parâmetros cadastrados.

A aplicação permite que o usuário informe a área construída em metros quadrados, selecione o tipo de obra e escolha o padrão de acabamento. Com base nesses dados, o sistema calcula a quantidade estimada de concreto, aço, alvenaria e o custo estimado da obra.

O objetivo principal é fornecer uma ferramenta simples, visual e funcional para apoiar decisões iniciais de engenharia, orçamento e planejamento.

---

## Funcionalidades

- Cadastro e edição de parâmetros por tipo de obra.
- Entrada da área construída em m².
- Seleção do tipo de obra:
  - Residencial.
  - Comercial.
  - Industrial.
- Seleção do padrão da obra:
  - Baixo.
  - Médio.
  - Alto.
- Cálculo automático de:
  - Quantidade de concreto em m³.
  - Quantidade de aço em kg.
  - Quantidade de alvenaria em m².
  - Custo estimado da obra em R$.
- Dashboard com indicadores principais.
- Aba de documentação e resumo One Page do processo.
